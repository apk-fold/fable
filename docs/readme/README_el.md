## Εγκατάσταση

1. Στο κινητό, άνοιξε τον σύνδεσμο **Λήψη του APK** παραπάνω (ή την πιο πρόσφατη [release](https://github.com/apk-fold/fable/releases/latest)).
2. Επίτρεψε την εγκατάσταση από τον browser αν το ζητήσει το Android και μετά εγκατάστησε.
3. Οι νέες εκδόσεις εγκαθίστανται πάνω από την παλιά: ίδια υπογραφή, τα δεδομένα διατηρούνται.

Κάθε αλλαγή κώδικα που ανεβαίνει στο `main` ξαναχτίζει αυτόματα το APK (GitHub Actions) και δημοσιεύει νέα release.

### Υπογραφή

Το κλειδί υπογραφής δεν βρίσκεται στο αποθετήριο. Το GitHub Actions το διαβάζει από το secret **`FABLE_KEYSTORE_B64`** (το αρχείο `.jks` κωδικοποιημένο σε base64, ο κωδικός `FABLE_KEYSTORE_PASSWORD` είναι προαιρετικός). Χωρίς αυτό το secret, το APK υπογράφεται με προσωρινό κλειδί: εγκαθίσταται, αλλά η επόμενη έκδοση θα ζητήσει να απεγκαταστήσεις την προηγούμενη.

## Τι κάνει η εφαρμογή

**Καταχώριση**
- Χτύπημα κάρτας: *Έναρξη*, *Διάλειμμα*, *Λήξη* — η μέρα δημιουργείται μόνη της (προαιρετική στρογγυλοποίηση στο τέταρτο).
- Χειροκίνητη καταχώριση: ημερομηνία, έναρξη → λήξη (υποστηρίζονται βάρδιες μετά τα μεσάνυχτα), διάλειμμα, κουμπιά **+ Υπερωρίες** (+15 λεπτά, +30 λεπτά, +1 ώρα).
- Ζωντανή προεπισκόπηση του υπολογισμού κατά την καταχώριση, προειδοποίηση αν δύο μέρες επικαλύπτονται.
- Επανάληψη μιας μέρας σε άλλες μέρες της εβδομάδας, αντιγραφή μιας μέρας, επιβολή ή αφαίρεση του επιδόματος γεύματος κατά περίπτωση.

**Απασχολήσεις** (μία ανά εργοδότη ή γραφείο), καθεμία με τους δικούς της κανόνες:
- Τύπος σύμβασης: Προσωρινή (intérim), Ορισμένου χρόνου (CDD), Αορίστου (CDI), Άλλη — μικτό ωρομίσθιο, χρώμα.
- **Υπερωρίες** ανά εβδομάδα ή ανά μέρα, με 2 κλιμάκια (π.χ. +25% από 35 ώρες, +50% από 43 ώρες).
- **Νυχτερινές ώρες** σε ρυθμιζόμενο διάστημα (21:00 → 6:00 από προεπιλογή) με τη δική τους προσαύξηση.
- **Κυριακές** και **αργίες**: ημερολόγιο **ηπειρωτικής Γαλλίας (Παρίσι)** από προεπιλογή, ή **Αλσατίας-Μοζέλας** (+ Μεγάλη Παρασκευή και 26 Δεκεμβρίου), ρυθμίζεται για όλες τις απασχολήσεις.
- Σώρευση προσαυξήσεων: προστίθενται ή μόνο η υψηλότερη· η νύχτα Σαββάτου προς Κυριακή μετρά με βάση τη μέρα έναρξης ή ώρα προς ώρα.
- **Επίδομα γεύματος** για κάθε εργάσιμη μέρα ή από ορισμένο αριθμό ωρών, **επίδομα μετακίνησης** ανά μέρα.
- **IFM** (αποζημίωση λήξης αποστολής, προσωρινή απασχόληση) ή **επίδομα επισφάλειας** (CDD) και **ICCP** (αποζημίωση αδείας), 10% + 10% από προεπιλογή.
- **Περίοδος μισθοδοσίας** για όλο τον μήνα ή μετατοπισμένη (π.χ. από τις 21 έως τις 20), προεπιλεγμένα ωράρια και διάλειμμα.

**Παρακολούθηση**
- Αρχική: χτύπημα κάρτας, τρέχουσα εβδομάδα με δείκτη του ορίου υπερωριών, σύνολα μήνα.
- Ιστορικό ανά μήνα, σε λίστα ομαδοποιημένη ανά εβδομάδα ή σε ημερολόγιο, φίλτρο ανά απασχόληση.
- Σύνοψη εβδομάδας / μήνα / έτους: ώρες, υπερωρίες ανά κλιμάκιο, νύχτα, Κυριακή, αργίες, μέρες εργασίας, γράφημα, ανάλυση από το μικτό έως τον **εκτιμώμενο καθαρό** (ρυθμιζόμενο ποσοστό κρατήσεων).
- **Εξαγωγή PDF** (φύλλο ωρών έτοιμο για αποστολή), **Excel .xlsx** και **CSV** — χωρίς συνδρομή.

**Τα υπόλοιπα**
- Υπενθύμιση με ειδοποίηση τις μέρες και την ώρα που επιλέγεις.
- **Όλα προσαρμόζονται** στις Ρυθμίσεις: σκούρο, μαύρο (AMOLED), ανοιχτό ή αυτόματο θέμα· κύριο χρώμα και χρώματα των προσαυξήσεων (παλέτα ή ελεύθερο χρώμα)· γραμματοσειρές· μέγεθος κειμένου· γωνίες· πυκνότητα· κινούμενα εφέ· μορφή διάρκειας (7 h 30, 7h30 ή 7,5 h)· διακριτική λειτουργία που κρύβει τα ποσά· οθόνη έναρξης· προβολή ιστορικού. Ελεύθερο χρώμα και για κάθε απασχόληση.
- Αντίγραφο ασφαλείας / επαναφορά σε αρχείο `.json`, αυτόματο εφεδρικό αντίγραφο στα ιδιωτικά αρχεία της εφαρμογής.
- Κανένα δεδομένο δεν φεύγει από το κινητό: χωρίς λογαριασμό, χωρίς διακομιστή, χωρίς διαφημίσεις.

## Πώς υπολογίζεται

Κάθε μέρα χωρίζεται λεπτό προς λεπτό. Για κάθε λεπτό εργασίας, το Fable ξέρει αν πέφτει νύχτα, Κυριακή ή αργία και σε ποιο κλιμάκιο υπερωριών (εβδομαδιαίο σύνολο από Δευτέρα έως Κυριακή, με χρονολογική σειρά). Το διάλειμμα αφαιρείται αναλογικά. Μια εβδομάδα που μοιράζεται σε δύο μήνες υπολογίζεται ολόκληρη και μετά μετρώνται μόνο οι μέρες της περιόδου.

- Μικτός μισθός = ώρες × ωρομίσθιο + προσαυξήσεις
- IFM / επίδομα επισφάλειας = μικτό × 10%
- ICCP = (μικτό + IFM) × 10%
- Εκτιμώμενος καθαρός = σύνολο μικτού − κρατήσεις (22% από προεπιλογή) + επιδόματα γεύματος και μετακίνησης

Είναι **εκτιμήσεις**: ισχύουν η συλλογική σύμβασή σου και η μισθοδοτική σου κατάσταση.

## Ανάπτυξη

```bash
npm install
npm run dev        # διεπαφή στον browser
npm test           # δοκιμές της μηχανής υπολογισμού
npm run sync       # build web + έργο Android (μετά το «npx cap add android» την πρώτη φορά)
npm run open       # ανοίγει το έργο στο Android Studio
```

Δομή: `src/core` (υπολογισμοί, αργίες, αποθήκευση, εξαγωγές PDF/Excel), `src/views` (οθόνες), `src/ui` (στοιχεία), `scripts/patch-android.mjs` (όνομα, εικονίδια, θέμα και υπογραφή του έργου Android), `tests/` (δοκιμές μηχανής και σενάρια διεπαφής).

Τεχνολογίες: HTML/CSS/JS χωρίς framework, [Vite](https://vitejs.dev), [Capacitor 8](https://capacitorjs.com), [pdf-lib](https://pdf-lib.js.org). Γραμματοσειρές Manrope και Unbounded (SIL Open Font License).
