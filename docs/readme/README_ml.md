## ഇൻസ്റ്റാൾ ചെയ്യാൻ

1. ഫോണിൽ, മുകളിലുള്ള **APK ഡൗൺലോഡ് ചെയ്യുക** ലിങ്ക് (അല്ലെങ്കിൽ ഏറ്റവും പുതിയ [release](https://github.com/apk-fold/fable/releases/latest)) തുറക്കുക.
2. Android ചോദിച്ചാൽ ബ്രൗസറിൽ നിന്നുള്ള ഇൻസ്റ്റാളേഷൻ അനുവദിക്കുക, തുടർന്ന് ഇൻസ്റ്റാൾ ചെയ്യുക.
3. പുതിയ പതിപ്പുകൾ പഴയതിന് മുകളിൽ ഇൻസ്റ്റാൾ ആകും: ഒരേ സിഗ്നേച്ചർ, ഡാറ്റ സുരക്ഷിതം.

`main`-ലേക്ക് push ചെയ്യുന്ന ഓരോ കോഡ് മാറ്റവും APK സ്വയമേവ വീണ്ടും ബിൽഡ് ചെയ്യുകയും (GitHub Actions) പുതിയ release പ്രസിദ്ധീകരിക്കുകയും ചെയ്യുന്നു.

### സൈനിംഗ്

സൈനിംഗ് കീ റിപ്പോസിറ്ററിയിൽ ഇല്ല. GitHub Actions അത് **`FABLE_KEYSTORE_B64`** എന്ന secret-ൽ നിന്ന് വായിക്കുന്നു (base64-ൽ എൻകോഡ് ചെയ്ത `.jks` ഫയൽ, `FABLE_KEYSTORE_PASSWORD` എന്ന പാസ്‌വേഡ് ഐച്ഛികം). ഈ secret ഇല്ലെങ്കിൽ APK ഒരു താൽക്കാലിക കീ ഉപയോഗിച്ച് സൈൻ ചെയ്യപ്പെടും: അത് ഇൻസ്റ്റാൾ ആകും, പക്ഷേ അടുത്ത പതിപ്പ് മുമ്പത്തേത് അൺഇൻസ്റ്റാൾ ചെയ്യാൻ ആവശ്യപ്പെടും.

## ആപ്പ് എന്തൊക്കെ ചെയ്യുന്നു

**രേഖപ്പെടുത്തൽ**
- ടൈം ക്ലോക്ക്: *ആരംഭിക്കുക*, *ഇടവേള*, *അവസാനിപ്പിക്കുക* — ദിവസം സ്വയം സൃഷ്ടിക്കപ്പെടുന്നു (15 മിനിറ്റിലേക്ക് റൗണ്ട് ചെയ്യൽ ഐച്ഛികം).
- മാനുവൽ എൻട്രി: തീയതി, ആരംഭം → അവസാനം (അർദ്ധരാത്രി കടക്കുന്ന ഷിഫ്റ്റുകൾ പിന്തുണയ്ക്കുന്നു), ഇടവേള, **+ ഓവർടൈം** ബട്ടണുകൾ (+15 മിനിറ്റ്, +30 മിനിറ്റ്, +1 മണിക്കൂർ).
- ടൈപ്പ് ചെയ്യുമ്പോൾ കണക്കുകൂട്ടലിന്റെ തത്സമയ പ്രിവ്യൂ, രണ്ട് ദിവസങ്ങൾ ഓവർലാപ്പ് ചെയ്താൽ മുന്നറിയിപ്പ്.
- ഒരു ദിവസം ആഴ്ചയിലെ മറ്റ് ദിവസങ്ങളിൽ ആവർത്തിക്കുക, ഒരു ദിവസം ഡ്യൂപ്ലിക്കേറ്റ് ചെയ്യുക, ഭക്ഷണ അലവൻസ് ഓരോ സന്ദർഭത്തിലും നിർബന്ധമായി ചേർക്കുകയോ ഒഴിവാക്കുകയോ ചെയ്യുക.

**ജോലികൾ** (ഓരോ തൊഴിലുടമയ്ക്കും ഏജൻസിക്കും ഒന്ന്), ഓരോന്നിനും സ്വന്തം നിയമങ്ങൾ:
- കരാർ തരം: താൽക്കാലികം (intérim), നിശ്ചിതകാലം (CDD), സ്ഥിരം (CDI), മറ്റുള്ളവ — മണിക്കൂറിലെ മൊത്ത നിരക്ക്, നിറം.
- ആഴ്ചയിലോ ദിവസത്തിലോ **ഓവർടൈം**, 2 ഘട്ടങ്ങളോടെ (ഉദാ. 35 മണിക്കൂർ മുതൽ +25%, 43 മണിക്കൂർ മുതൽ +50%).
- ക്രമീകരിക്കാവുന്ന സമയപരിധിയിൽ **രാത്രി സമയം** (സ്ഥിരസ്ഥിതി 21:00 → 6:00) അതിന്റേതായ അധിക നിരക്കോടെ.
- **ഞായർ**, **പൊതു അവധികൾ**: സ്ഥിരസ്ഥിതിയായി **ഫ്രാൻസ് മെയിൻലാൻഡ് (പാരീസ്)** കലണ്ടർ, അല്ലെങ്കിൽ **അൽസാസ്-മോസൽ** (+ ദുഃഖവെള്ളി, ഡിസംബർ 26), എല്ലാ ജോലികൾക്കും ഒരുമിച്ച് ക്രമീകരിക്കാം.
- അധിക നിരക്കുകൾ കൂട്ടൽ: ഒന്നിച്ച് കൂട്ടുക അല്ലെങ്കിൽ ഏറ്റവും ഉയർന്നത് മാത്രം; ശനി മുതൽ ഞായർ വരെയുള്ള രാത്രി ആരംഭ ദിവസം അനുസരിച്ചോ മണിക്കൂർ തോറുമോ കണക്കാക്കുന്നു.
- ഓരോ ജോലി ദിവസത്തിനും അല്ലെങ്കിൽ നിശ്ചിത മണിക്കൂറുകൾ മുതൽ **ഭക്ഷണ അലവൻസ്**, ദിവസേന **യാത്രാ അലവൻസ്**.
- **IFM** (താൽക്കാലിക ജോലിയുടെ അവസാന നഷ്ടപരിഹാരം) അല്ലെങ്കിൽ **കരാർ അവസാന ബോണസ്** (CDD), **ICCP** (ശമ്പളത്തോടെയുള്ള അവധിക്കുള്ള നഷ്ടപരിഹാരം), സ്ഥിരസ്ഥിതി 10% + 10%.
- മുഴുവൻ മാസമോ മാറ്റിയതോ ആയ **ശമ്പള കാലയളവ്** (ഉദാ. 21 മുതൽ 20 വരെ), സ്ഥിരസ്ഥിതി സമയവും ഇടവേളയും.

**ട്രാക്കിംഗ്**
- ഹോം: ടൈം ക്ലോക്ക്, ഓവർടൈം പരിധി ഗേജോടെ നിലവിലെ ആഴ്ച, മാസത്തെ ആകെത്തുകകൾ.
- മാസം തിരിച്ചുള്ള ചരിത്രം, ആഴ്ച തിരിച്ച് ഗ്രൂപ്പ് ചെയ്ത ലിസ്റ്റായോ കലണ്ടറായോ, ജോലി അനുസരിച്ച് ഫിൽട്ടർ.
- ആഴ്ച / മാസം / വർഷം സംഗ്രഹം: മണിക്കൂറുകൾ, ഘട്ടം തിരിച്ചുള്ള ഓവർടൈം, രാത്രി, ഞായർ, അവധികൾ, ജോലി ചെയ്ത ദിവസങ്ങൾ, ഗ്രാഫ്, മൊത്ത ശമ്പളം മുതൽ **കണക്കാക്കിയ അറ്റ ശമ്പളം** വരെയുള്ള വിശദാംശം (കിഴിവ് നിരക്ക് ക്രമീകരിക്കാം).
- **PDF എക്‌സ്‌പോർട്ട്** (അയയ്ക്കാൻ തയ്യാറായ ടൈംഷീറ്റ്), **Excel .xlsx**, **CSV** — സബ്‌സ്‌ക്രിപ്‌ഷൻ ഇല്ലാതെ.

**ബാക്കിയുള്ളവ**
- നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന ദിവസങ്ങളിലും സമയത്തും അറിയിപ്പിലൂടെ ഓർമ്മപ്പെടുത്തൽ.
- ക്രമീകരണങ്ങളിൽ **എല്ലാം വ്യക്തിഗതമാക്കാം**: ഡാർക്ക്, ബ്ലാക്ക് (AMOLED), ലൈറ്റ് അല്ലെങ്കിൽ ഓട്ടോ തീം; പ്രധാന നിറവും അധിക നിരക്കുകളുടെ നിറങ്ങളും (പാലറ്റ് അല്ലെങ്കിൽ ഇഷ്ടമുള്ള നിറം); ഫോണ്ടുകൾ; ടെക്‌സ്റ്റ് വലുപ്പം; കോണുകൾ; സാന്ദ്രത; ആനിമേഷനുകൾ; സമയദൈർഘ്യ ഫോർമാറ്റ് (7 h 30, 7h30 അല്ലെങ്കിൽ 7,5 h); തുകകൾ മറയ്ക്കുന്ന ഡിസ്‌ക്രീറ്റ് മോഡ്; തുടക്ക സ്ക്രീൻ; ചരിത്ര കാഴ്ച. ഓരോ ജോലിക്കും ഇഷ്ടമുള്ള നിറവും.
- `.json` ഫയലിലേക്ക് ബാക്കപ്പ് / പുനഃസ്ഥാപനം, ആപ്പിന്റെ സ്വകാര്യ ഫയലുകളിൽ സ്വയമേവയുള്ള സുരക്ഷാ പകർപ്പ്.
- ഒരു ഡാറ്റയും ഫോൺ വിട്ടുപോകുന്നില്ല: അക്കൗണ്ട് ഇല്ല, സെർവർ ഇല്ല, പരസ്യങ്ങൾ ഇല്ല.

## എങ്ങനെ കണക്കാക്കുന്നു

ഓരോ ദിവസവും മിനിറ്റ് തോറും വിഭജിക്കുന്നു. ജോലി ചെയ്ത ഓരോ മിനിറ്റും രാത്രിയിലാണോ, ഞായറാഴ്ചയാണോ, പൊതു അവധിയിലാണോ, ഏത് ഓവർടൈം ഘട്ടത്തിലാണ് (തിങ്കൾ മുതൽ ഞായർ വരെയുള്ള ആഴ്ചയിലെ ആകെത്തുക, കാലക്രമത്തിൽ) എന്ന് Fable-ന് അറിയാം. ഇടവേള ആനുപാതികമായി കുറയ്ക്കുന്നു. രണ്ട് മാസങ്ങളിലായി വരുന്ന ആഴ്ച മുഴുവനായി കണക്കാക്കുന്നു, തുടർന്ന് കാലയളവിനുള്ളിലെ ദിവസങ്ങൾ മാത്രം എണ്ണുന്നു.

- മൊത്ത ശമ്പളം = മണിക്കൂറുകൾ × നിരക്ക് + അധിക നിരക്കുകൾ
- IFM / കരാർ അവസാന ബോണസ് = മൊത്തം × 10%
- ICCP = (മൊത്തം + IFM) × 10%
- കണക്കാക്കിയ അറ്റ ശമ്പളം = ആകെ മൊത്തം − കിഴിവുകൾ (സ്ഥിരസ്ഥിതി 22%) + ഭക്ഷണ, യാത്രാ അലവൻസുകൾ

ഇവ **കണക്കാക്കിയ മൂല്യങ്ങൾ** മാത്രമാണ്: നിങ്ങളുടെ കൂട്ടായ കരാറും ശമ്പള സ്ലിപ്പുമാണ് അന്തിമം.

## ഡെവലപ്‌മെന്റ്

```bash
npm install
npm run dev        # ബ്രൗസറിൽ ഇന്റർഫേസ്
npm test           # കണക്കുകൂട്ടൽ എഞ്ചിൻ ടെസ്റ്റുകൾ
npm run sync       # വെബ് ബിൽഡ് + Android പ്രോജക്റ്റ് (ആദ്യ തവണ "npx cap add android"-ന് ശേഷം)
```
