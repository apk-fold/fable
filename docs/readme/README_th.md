## การติดตั้ง

1. บนโทรศัพท์ เปิดลิงก์ **ดาวน์โหลด APK** ด้านบน (หรือ [release](https://github.com/apk-fold/fable/releases/latest) ล่าสุด)
2. อนุญาตการติดตั้งจากเบราว์เซอร์หาก Android ถาม แล้วติดตั้ง
3. เวอร์ชันใหม่จะติดตั้งทับเวอร์ชันเก่า: ลายเซ็นเดียวกัน ข้อมูลยังอยู่ครบ

ทุกการเปลี่ยนแปลงโค้ดที่ push ขึ้น `main` จะคอมไพล์ APK ใหม่โดยอัตโนมัติ (GitHub Actions) และเผยแพร่ release ใหม่

### การลงนาม

คีย์ลงนามไม่ได้อยู่ในรีโพซิทอรี GitHub Actions อ่านคีย์จาก secret **`FABLE_KEYSTORE_B64`** (ไฟล์ `.jks` ที่เข้ารหัสแบบ base64 โดยรหัสผ่าน `FABLE_KEYSTORE_PASSWORD` จะใส่หรือไม่ก็ได้) หากไม่มี secret นี้ APK จะถูกลงนามด้วยคีย์ชั่วคราว: ติดตั้งได้ แต่เวอร์ชันถัดไปจะขอให้ถอนการติดตั้งเวอร์ชันก่อนหน้า

## แอปทำอะไรได้บ้าง

**การบันทึก**
- นาฬิกาตอกบัตร: *เริ่ม*, *พัก*, *เลิก* — ระบบจะสร้างวันทำงานให้เอง (เลือกปัดเศษเป็นช่วง 15 นาทีได้)
- บันทึกเอง: วันที่, เริ่ม → เลิก (รองรับกะข้ามเที่ยงคืน), เวลาพัก, ปุ่ม **+ ล่วงเวลา** (+15 นาที, +30 นาที, +1 ชม.)
- แสดงตัวอย่างผลการคำนวณสด ๆ ระหว่างบันทึก และเตือนหากสองวันเวลาทับซ้อนกัน
- ทำซ้ำวันหนึ่งไปยังวันอื่นในสัปดาห์, ทำสำเนาวัน, บังคับเพิ่มหรือตัดค่าอาหารเป็นรายวัน

**งาน** (หนึ่งรายการต่อนายจ้างหรือเอเจนซี) แต่ละงานมีกฎของตัวเอง:
- ประเภทสัญญา: ชั่วคราว (intérim), มีกำหนดเวลา (CDD), ไม่มีกำหนดเวลา (CDI), อื่น ๆ — ค่าจ้างรายชั่วโมงก่อนหัก, สี
- **ล่วงเวลา** รายสัปดาห์หรือรายวัน แบ่ง 2 ขั้น (เช่น +25% ตั้งแต่ 35 ชม., +50% ตั้งแต่ 43 ชม.)
- **ชั่วโมงกลางคืน** ในช่วงเวลาที่ปรับได้ (ค่าเริ่มต้น 21:00 → 06:00) พร้อมอัตราเพิ่มของตัวเอง
- **วันอาทิตย์** และ **วันหยุดนักขัตฤกษ์**: ค่าเริ่มต้นเป็นปฏิทิน **ฝรั่งเศสแผ่นดินใหญ่ (ปารีส)** หรือ **อาลซาส-โมแซล** (+ วันศุกร์ประเสริฐและ 26 ธันวาคม) ตั้งค่าครั้งเดียวสำหรับทุกงาน
- การรวมอัตราเพิ่ม: บวกรวมกันหรือใช้เฉพาะอัตราสูงสุด; คืนวันเสาร์ต่อวันอาทิตย์คิดตามวันที่เริ่มงานหรือคิดทีละชั่วโมง
- **ค่าอาหาร** ทุกวันทำงานหรือเมื่อทำงานครบจำนวนชั่วโมงที่กำหนด, **ค่าเดินทาง** รายวัน
- **IFM** (เงินชดเชยสิ้นสุดภารกิจงานชั่วคราว) หรือ **เงินชดเชยสิ้นสุดสัญญา** (CDD) และ **ICCP** (เงินชดเชยวันลาพักร้อน) ค่าเริ่มต้น 10% + 10%
- **รอบจ่ายเงินเดือน** เต็มเดือนหรือแบบเลื่อน (เช่น วันที่ 21 ถึงวันที่ 20) เวลาทำงานและเวลาพักเริ่มต้น

**การติดตาม**
- หน้าหลัก: นาฬิกาตอกบัตร, สัปดาห์ปัจจุบันพร้อมมาตรวัดเกณฑ์ล่วงเวลา, ยอดรวมของเดือน
- ประวัติรายเดือน แสดงเป็นรายการจัดกลุ่มตามสัปดาห์หรือเป็นปฏิทิน กรองตามงานได้
- สรุปรายสัปดาห์ / เดือน / ปี: ชั่วโมง, ล่วงเวลาแต่ละขั้น, กลางคืน, วันอาทิตย์, วันหยุด, จำนวนวันทำงาน, กราฟ, รายละเอียดตั้งแต่เงินก่อนหักจนถึง **เงินสุทธิโดยประมาณ** (ปรับอัตราการหักได้)
- **ส่งออก PDF** (ใบบันทึกเวลาพร้อมส่ง), **Excel .xlsx** และ **CSV** — ไม่ต้องสมัครสมาชิก

**อื่น ๆ**
- แจ้งเตือนในวันและเวลาที่คุณเลือก
- **ปรับแต่งได้ทุกอย่าง** ในการตั้งค่า: ธีมมืด, ดำ (AMOLED), สว่าง หรืออัตโนมัติ; สีหลักและสีของอัตราเพิ่มต่าง ๆ (จานสีหรือเลือกสีเอง); ฟอนต์; ขนาดตัวอักษร; มุมโค้ง; ความหนาแน่น; แอนิเมชัน; รูปแบบระยะเวลา (7 h 30, 7h30 หรือ 7,5 h); โหมดเงียบที่ซ่อนจำนวนเงิน; หน้าจอเปิดแอป; มุมมองประวัติ เลือกสีเองได้สำหรับแต่ละงานด้วย
- สำรอง / กู้คืนเป็นไฟล์ `.json` และมีสำเนาสำรองอัตโนมัติในไฟล์ส่วนตัวของแอป
- ไม่มีข้อมูลใดออกจากโทรศัพท์: ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีโฆษณา

## วิธีคำนวณ

แต่ละวันถูกแบ่งเป็นรายนาที สำหรับทุกนาทีที่ทำงาน Fable รู้ว่าตรงกับกลางคืน วันอาทิตย์ หรือวันหยุดนักขัตฤกษ์หรือไม่ และอยู่ในขั้นล่วงเวลาใด (ยอดรวมรายสัปดาห์จากวันจันทร์ถึงวันอาทิตย์ ตามลำดับเวลา) เวลาพักจะถูกหักตามสัดส่วน สัปดาห์ที่คร่อมสองเดือนจะคำนวณทั้งสัปดาห์ แล้วนับเฉพาะวันที่อยู่ในรอบเท่านั้น

- เงินเดือนก่อนหัก = ชั่วโมง × อัตรา + อัตราเพิ่ม
- IFM / เงินชดเชยสิ้นสุดสัญญา = เงินก่อนหัก × 10%
- ICCP = (เงินก่อนหัก + IFM) × 10%
- เงินสุทธิโดยประมาณ = ยอดรวมก่อนหัก − เงินสมทบ (ค่าเริ่มต้น 22%) + ค่าอาหารและค่าเดินทาง

ทั้งหมดนี้เป็น **ค่าประมาณ**: ข้อตกลงร่วมของสายงานและสลิปเงินเดือนของคุณคือสิ่งที่ใช้อ้างอิงจริง

## การพัฒนา

```bash
npm install
npm run dev        # อินเทอร์เฟซในเบราว์เซอร์
npm test           # ทดสอบเอนจินคำนวณ
npm run sync       # build เว็บ + โปรเจกต์ Android (ครั้งแรกหลังจาก "npx cap add android")
npm run open       # เปิดโปรเจกต์ใน Android Studio
```

โครงสร้าง: `src/core` (การคำนวณ, วันหยุด, การจัดเก็บ, การส่งออก PDF/Excel), `src/views` (หน้าจอ), `src/ui` (คอมโพเนนต์), `scripts/patch-android.mjs` (ชื่อ, ไอคอน, ธีม และการลงนามของโปรเจกต์ Android), `tests/` (ทดสอบเอนจินและขั้นตอนการใช้งานอินเทอร์เฟซ)

เทคโนโลยี: HTML/CSS/JS ไม่ใช้เฟรมเวิร์ก, [Vite](https://vitejs.dev), [Capacitor 8](https://capacitorjs.com), [pdf-lib](https://pdf-lib.js.org) ฟอนต์ Manrope และ Unbounded (SIL Open Font License)
