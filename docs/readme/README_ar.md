## التثبيت

1. على الهاتف، افتح رابط **تنزيل ملف APK** أعلاه (أو أحدث [release](https://github.com/apk-fold/fable/releases/latest)).
2. اسمح بالتثبيت من المتصفح إذا طلب Android ذلك، ثم ثبّت التطبيق.
3. تُثبَّت الإصدارات الجديدة فوق القديمة: التوقيع نفسه، والبيانات محفوظة.

كل تعديل على الشيفرة يُدفع إلى `main` يعيد بناء ملف APK تلقائيًا (GitHub Actions) وينشر release جديدًا.

### التوقيع

مفتاح التوقيع ليس في المستودع. يقرؤه GitHub Actions من السر **`FABLE_KEYSTORE_B64`** (ملف `.jks` مرمّز بـ base64، وكلمة المرور `FABLE_KEYSTORE_PASSWORD` اختيارية). من دون هذا السر يُوقَّع ملف APK بمفتاح مؤقت: سيُثبَّت، لكن الإصدار التالي سيطلب إلغاء تثبيت الإصدار السابق.

## ما الذي يفعله التطبيق

**الإدخال**
- ساعة الدوام: *ابدأ*، *استراحة*، *إنهاء* — يُنشأ اليوم تلقائيًا (التقريب إلى ربع ساعة اختياري).
- إدخال يدوي: التاريخ، البداية ← النهاية (مع دعم المناوبات التي تتجاوز منتصف الليل)، الاستراحة، وأزرار **+ ساعات إضافية** (+15 دقيقة، +30 دقيقة، +1 ساعة).
- معاينة مباشرة للحساب أثناء الإدخال، وتنبيه إذا تداخل يومان.
- تكرار يوم على أيام أخرى من الأسبوع، ونسخ يوم، وفرض بدل الوجبة أو حذفه حسب كل حالة.

**المهام** (مهمة لكل صاحب عمل أو وكالة)، ولكل منها قواعدها:
- نوع العقد: مؤقت (intérim)، محدد المدة (CDD)، غير محدد المدة (CDI)، آخر — الأجر الإجمالي بالساعة، اللون.
- **ساعات إضافية** أسبوعيًا أو يوميًا، على شريحتين (مثلًا +25% بدءًا من 35 ساعة، +50% بدءًا من 43 ساعة).
- **ساعات ليلية** ضمن فترة قابلة للضبط (من 21:00 إلى 6:00 افتراضيًا) مع علاوتها الخاصة.
- **الأحد** و**العطل الرسمية**: تقويم **فرنسا القارية (باريس)** افتراضيًا، أو **الألزاس-موزيل** (+ الجمعة العظيمة و26 ديسمبر)، ويُضبط لجميع المهام.
- جمع العلاوات: تُجمع معًا أو تُحتسب الأعلى فقط؛ وليلة السبت إلى الأحد تُحسب حسب يوم البدء أو ساعة بساعة.
- **بدل وجبة** عن كل يوم عمل أو بدءًا من عدد معيّن من الساعات، و**بدل تنقّل** يومي.
- **IFM** (تعويض نهاية المهمة في العمل المؤقت) أو **علاوة الهشاشة** (CDD) و**ICCP** (تعويض الإجازة المدفوعة)، ‏10% + 10% افتراضيًا.
- **فترة الرواتب** على الشهر كاملًا أو بإزاحة (مثلًا من 21 إلى 20)، مع ساعات واستراحة افتراضية.

**المتابعة**
- الصفحة الرئيسية: ساعة الدوام، الأسبوع الحالي مع مقياس عتبة الساعات الإضافية، مجاميع الشهر.
- سجل حسب الشهر، كقائمة مجمّعة حسب الأسبوع أو كتقويم، مع تصفية حسب المهمة.
- ملخص الأسبوع / الشهر / السنة: الساعات، الساعات الإضافية لكل شريحة، الليل، الأحد، العطل، أيام العمل، رسم بياني، وتفصيل من الإجمالي حتى **الصافي التقديري** (نسبة الاقتطاعات قابلة للضبط).
- **تصدير PDF** (كشف ساعات جاهز للإرسال)، و**Excel .xlsx** و**CSV** — دون اشتراك.

**البقية**
- تذكير بإشعار في الأيام والساعة التي تختارها.
- **كل شيء قابل للتخصيص** في الإعدادات: سمة داكنة أو سوداء (AMOLED) أو فاتحة أو تلقائية؛ اللون الرئيسي وألوان العلاوات (لوحة ألوان أو لون حر)؛ الخطوط؛ حجم النص؛ الزوايا؛ الكثافة؛ الحركات؛ صيغة المدد (7 h 30 أو 7h30 أو 7,5 h)؛ وضع خفي يُخفي المبالغ؛ شاشة البدء؛ طريقة عرض السجل. ولون حر لكل مهمة أيضًا.
- نسخ احتياطي / استعادة بملف `.json`، ونسخة أمان تلقائية في الملفات الخاصة بالتطبيق.
- لا تغادر أي بيانات الهاتف: لا حساب، لا خادم، لا إعلانات.

## طريقة الحساب

يُقسَّم كل يوم دقيقة بدقيقة. لكل دقيقة عمل، يعرف Fable إن كانت تقع ليلًا أو يوم أحد أو في عطلة رسمية، وفي أي شريحة من الساعات الإضافية (المجموع الأسبوعي من الاثنين إلى الأحد بالترتيب الزمني). تُخصم الاستراحة بالتناسب. والأسبوع الذي يمتد على شهرين يُحسب كاملًا، ثم تُحتسب الأيام الواقعة ضمن الفترة فقط.

- الأجر الإجمالي = الساعات × الأجر + العلاوات
- IFM / علاوة الهشاشة = الإجمالي × 10%
- ICCP = (الإجمالي + IFM) × 10%
- الصافي التقديري = مجموع الإجمالي − الاقتطاعات (22% افتراضيًا) + بدلات الوجبات والتنقّل

هذه **تقديرات**: المرجع هو اتفاقيتك الجماعية وقسيمة راتبك.

## التطوير

```bash
npm install
npm run dev        # الواجهة في المتصفح
npm test           # اختبارات محرك الحساب
npm run sync       # بناء الويب + مشروع Android (بعد "npx cap add android" في المرة الأولى)
npm run open       # يفتح المشروع في Android Studio
```

البنية: `src/core` (الحسابات، العطل الرسمية، التخزين، تصدير PDF/Excel)، `src/views` (الشاشات)، `src/ui` (المكوّنات)، `scripts/patch-android.mjs` (اسم مشروع Android وأيقوناته وسمته وتوقيعه)، `tests/` (اختبارات المحرك وسيناريوهات الواجهة).
