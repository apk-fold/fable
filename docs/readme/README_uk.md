## Установлення

1. На телефоні відкрий посилання **Завантажити APK** вище (або останній [release](https://github.com/apk-fold/fable/releases/latest)).
2. Якщо Android попросить, дозволь установлення з браузера, потім установи.
3. Нові версії встановлюються поверх старої: підпис той самий, дані зберігаються.

Кожна зміна коду, надіслана в `main`, автоматично перезбирає APK (GitHub Actions) і публікує новий release.

### Підпис

Ключа підпису в репозиторії немає. GitHub Actions бере його із секрету **`FABLE_KEYSTORE_B64`** (файл `.jks` у base64, пароль `FABLE_KEYSTORE_PASSWORD` необов'язковий). Без цього секрету APK підписується тимчасовим ключем: він установиться, але наступна версія попросить видалити попередню.

## Що вміє застосунок

**Введення**
- Табель: *Почати*, *Перерва*, *Завершити* — день створюється сам (за бажанням з округленням до чверті години).
- Ручне введення: дата, початок → кінець (зміни через північ підтримуються), перерва, кнопки **+ Понаднормові** (+15 хв, +30 хв, +1 год).
- Живий попередній перегляд розрахунку під час введення, попередження, якщо два дні перетинаються.
- Повторити день на інші дні тижня, дублювати день, примусово додати або прибрати оплату харчування для окремого дня.

**Місця роботи** (по одному на роботодавця чи агентство), у кожного свої правила:
- Тип договору: Тимчасова робота (intérim), Строковий (CDD), Безстроковий (CDI), Інший — погодинна ставка брутто, колір.
- **Понаднормові** за тиждень або за день, з 2 ступенями (наприклад, +25% від 35 год, +50% від 43 год).
- **Нічні години** в налаштовуваному проміжку (за замовчуванням 21:00 → 6:00) зі своєю надбавкою.
- **Неділі** та **свята**: за замовчуванням календар **материкової Франції (Париж)** або **Ельзасу-Мозелю** (+ Страсна п'ятниця і 26 грудня), задається для всіх місць роботи.
- Поєднання надбавок: додаються або враховується лише найбільша; ніч із суботи на неділю рахується за днем початку або погодинно.
- **Оплата харчування** за кожен робочий день або починаючи з певної кількості годин, **транспортна компенсація** за день.
- **IFM** (компенсація після завершення тимчасової місії) або **компенсація після завершення строкового договору** (CDD) і **ICCP** (компенсація за відпустку), за замовчуванням 10% + 10%.
- **Розрахунковий період** — повний місяць або зі зсувом (наприклад, з 21-го по 20-те), години й перерва за замовчуванням.

**Облік**
- Головний екран: табель, поточний тиждень зі шкалою порогу понаднормових, підсумки місяця.
- Історія за місяцями — списком, згрупованим за тижнями, або календарем, з фільтром за місцем роботи.
- Підсумки за тиждень / місяць / рік: години, понаднормові за ступенями, ніч, неділі, свята, відпрацьовані дні, графік, розшифровка від брутто до **орієнтовної суми на руки** (ставка утримань налаштовується).
- **Експорт у PDF** (табель, готовий до надсилання), **Excel .xlsx** і **CSV** — без підписки.

**Решта**
- Нагадування сповіщенням у вибрані дні та час.
- **Усе налаштовується** в Налаштуваннях: темна, чорна (AMOLED), світла або автоматична тема; основний колір і кольори надбавок (палітра або будь-який колір); шрифти; розмір тексту; заокруглення; щільність; анімації; формат тривалості (7 h 30, 7h30 або 7,5 h); стриманий режим, що приховує суми; стартовий екран; вигляд історії. Будь-який колір і для кожного місця роботи.
- Резервне копіювання / відновлення у файл `.json`, автоматична запасна копія в приватних файлах застосунку.
- Жодні дані не покидають телефон: ні облікового запису, ні сервера, ні реклами.

## Як це рахується

Кожен день ділиться по хвилинах. Для кожної відпрацьованої хвилини Fable знає, чи припадає вона на ніч, неділю чи свято і до якого ступеня понаднормових належить (тижневий підсумок із понеділка по неділю, у хронологічному порядку). Перерва віднімається пропорційно. Тиждень на межі двох місяців рахується повністю, а потім ураховуються лише дні всередині періоду.

- Зарплата брутто = години × ставка + надбавки
- IFM / компенсація після завершення договору = брутто × 10%
- ICCP = (брутто + IFM) × 10%
- Орієнтовно на руки = усього брутто − утримання (за замовчуванням 22%) + харчування й транспорт

Це **оцінки**: вирішальними є твій колективний договір і розрахунковий лист.

## Розробка

```bash
npm install
npm run dev        # інтерфейс у браузері
npm test           # тести рушія розрахунку
npm run sync       # веб-збірка + Android-проєкт (уперше після «npx cap add android»)
npm run open       # відкриває проєкт в Android Studio
```

Структура: `src/core` (розрахунки, свята, зберігання, експорт у PDF/Excel), `src/views` (екрани), `src/ui` (компоненти), `scripts/patch-android.mjs` (назва, значки, тема й підпис Android-проєкту), `tests/` (тести рушія та сценарії інтерфейсу).

Стек: HTML/CSS/JS без фреймворку, [Vite](https://vitejs.dev), [Capacitor 8](https://capacitorjs.com), [pdf-lib](https://pdf-lib.js.org). Шрифти Manrope і Unbounded (SIL Open Font License).
