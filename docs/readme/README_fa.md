## نصب

1. روی گوشی، پیوند **دانلود APK** بالا (یا آخرین [release](https://github.com/apk-fold/fable/releases/latest)) را باز کنید.
2. اگر Android خواست، نصب از مرورگر را مجاز کنید و سپس نصب کنید.
3. نسخه‌های جدید روی نسخهٔ قدیمی نصب می‌شوند: امضای یکسان، داده‌ها حفظ می‌شوند.

هر تغییری که در کد به `main` فرستاده شود، APK را به‌طور خودکار دوباره می‌سازد (GitHub Actions) و یک release جدید منتشر می‌کند.

### امضا

کلید امضا در مخزن نیست. GitHub Actions آن را از راز **`FABLE_KEYSTORE_B64`** می‌خواند (فایل `.jks` رمزگذاری‌شده با base64، گذرواژهٔ `FABLE_KEYSTORE_PASSWORD` اختیاری است). بدون این راز، APK با یک کلید موقت امضا می‌شود: نصب می‌شود، اما نسخهٔ بعدی از شما می‌خواهد نسخهٔ قبلی را حذف کنید.

## برنامه چه کار می‌کند

**ورود اطلاعات**
- ساعت حضور: *شروع*، *استراحت*، *پایان* — روز کاری خودبه‌خود ساخته می‌شود (گرد کردن به یک‌ربع ساعت اختیاری است).
- ورود دستی: تاریخ، شروع ← پایان (شیفت‌هایی که از نیمه‌شب می‌گذرند پشتیبانی می‌شوند)، استراحت، دکمه‌های **+ اضافه‌کاری** (‏+۱۵ دقیقه، +۳۰ دقیقه، +۱ ساعت).
- پیش‌نمایش زندهٔ محاسبه هنگام ورود اطلاعات، هشدار در صورت هم‌پوشانی دو روز.
- تکرار یک روز در روزهای دیگر هفته، تکثیر یک روز، افزودن یا حذف اجباری کمک‌هزینهٔ غذا به‌صورت موردی.

**مأموریت‌ها** (یکی برای هر کارفرما یا آژانس)، هر کدام با قواعد خودش:
- نوع قرارداد: موقت (intérim)، مدت‌دار (CDD)، دائمی (CDI)، سایر — نرخ ناخالص ساعتی، رنگ.
- **اضافه‌کاری** هفتگی یا روزانه، با ۲ پله (مثلاً +۲۵٪ از ۳۵ ساعت، +۵۰٪ از ۴۳ ساعت).
- **ساعات شب** در بازه‌ای قابل تنظیم (پیش‌فرض ۲۱ ← ۶) با فوق‌العادهٔ خودش.
- **یکشنبه** و **تعطیلات رسمی**: تقویم **فرانسهٔ اصلی (پاریس)** به‌طور پیش‌فرض، یا **آلزاس-موزل** (+ جمعهٔ مقدس و ۲۶ دسامبر)، قابل تنظیم برای همهٔ مأموریت‌ها.
- جمع فوق‌العاده‌ها: با هم جمع می‌شوند یا فقط بیشترین آن‌ها؛ شب شنبه به یکشنبه بر اساس روز شروع یا ساعت به ساعت حساب می‌شود.
- **کمک‌هزینهٔ غذا** برای هر روز کاری یا از تعداد مشخصی ساعت به بعد، **کمک‌هزینهٔ رفت‌وآمد** روزانه.
- **IFM** (غرامت پایان مأموریت در کار موقت) یا **پاداش ناپایداری** (CDD) و **ICCP** (غرامت مرخصی با حقوق)، به‌طور پیش‌فرض ۱۰٪ + ۱۰٪.
- **دورهٔ حقوق** کل ماه یا جابه‌جاشده (مثلاً از ۲۱ تا ۲۰)، ساعت‌ها و استراحت پیش‌فرض.

**پیگیری**
- صفحهٔ اصلی: ساعت حضور، هفتهٔ جاری با نشانگر آستانهٔ اضافه‌کاری، جمع‌های ماه.
- تاریخچه بر اساس ماه، به‌صورت فهرستی گروه‌بندی‌شده بر اساس هفته یا تقویم، با فیلتر بر اساس مأموریت.
- خلاصهٔ هفته / ماه / سال: ساعت‌ها، اضافه‌کاری هر پله، شب، یکشنبه، تعطیلات، روزهای کارکرد، نمودار، جزئیات از ناخالص تا **خالص تخمینی** (نرخ کسورات قابل تنظیم).
- **خروجی PDF** (برگهٔ ساعات آمادهٔ ارسال)، **Excel .xlsx** و **CSV** — بدون اشتراک.

**بقیه**
- یادآوری با اعلان در روزها و ساعتی که انتخاب می‌کنید.
- **همه‌چیز در تنظیمات قابل شخصی‌سازی است**: تم تیره، سیاه (AMOLED)، روشن یا خودکار؛ رنگ اصلی و رنگ فوق‌العاده‌ها (پالت یا رنگ آزاد)؛ فونت‌ها؛ اندازهٔ متن؛ گوشه‌ها؛ تراکم؛ انیمیشن‌ها؛ قالب مدت‌زمان (7 h 30، 7h30 یا 7,5 h)؛ حالت محتاط که مبالغ را پنهان می‌کند؛ صفحهٔ شروع؛ نمای تاریخچه. رنگ آزاد برای هر مأموریت هم ممکن است.
- پشتیبان‌گیری / بازیابی در فایل `.json`، نسخهٔ پشتیبان خودکار در فایل‌های خصوصی برنامه.
- هیچ داده‌ای از گوشی خارج نمی‌شود: بدون حساب، بدون سرور، بدون تبلیغ.

## نحوهٔ محاسبه

هر روز دقیقه به دقیقه تقسیم می‌شود. برای هر دقیقهٔ کاری، Fable می‌داند که آیا در شب، یکشنبه یا تعطیل رسمی است و در کدام پلهٔ اضافه‌کاری قرار می‌گیرد (جمع هفتگی از دوشنبه تا یکشنبه، به ترتیب زمانی). استراحت به نسبت کسر می‌شود. هفته‌ای که میان دو ماه قرار دارد کامل محاسبه می‌شود و سپس فقط روزهای داخل دوره شمرده می‌شوند.

- حقوق ناخالص = ساعت‌ها × نرخ + فوق‌العاده‌ها
- IFM / پاداش ناپایداری = ناخالص × ۱۰٪
- ICCP = (ناخالص + IFM) × ۱۰٪
- خالص تخمینی = جمع ناخالص − کسورات (۲۲٪ پیش‌فرض) + کمک‌هزینهٔ غذا و رفت‌وآمد

این‌ها **تخمین** هستند: ملاک، پیمان دسته‌جمعی و فیش حقوقی شماست.

## توسعه

```bash
npm install
npm run dev        # رابط کاربری در مرورگر
npm test           # آزمون‌های موتور محاسبه
npm run sync       # ساخت وب + پروژهٔ Android (بار اول پس از «npx cap add android»)
npm run open       # پروژه را در Android Studio باز می‌کند
```

ساختار: `src/core` (محاسبات، تعطیلات رسمی، ذخیره‌سازی، خروجی PDF/Excel)، `src/views` (صفحه‌ها)، `src/ui` (اجزا)، `scripts/patch-android.mjs` (نام، آیکون‌ها، تم و امضای پروژهٔ Android)، `tests/` (آزمون‌های موتور و سناریوهای رابط).

فناوری‌ها: HTML/CSS/JS بدون فریم‌ورک، [Vite](https://vitejs.dev)، [Capacitor 8](https://capacitorjs.com)، [pdf-lib](https://pdf-lib.js.org). فونت‌های Manrope و Unbounded (SIL Open Font License).
