## Установка

1. На телефоне открой ссылку **Скачать APK** выше (или последний [release](https://github.com/apk-fold/fable/releases/latest)).
2. Если Android попросит, разреши установку из браузера, затем установи.
3. Новые версии ставятся поверх старой: подпись та же, данные сохраняются.

Каждое изменение кода, отправленное в `main`, автоматически пересобирает APK (GitHub Actions) и публикует новый release.

### Подпись

Ключа подписи в репозитории нет. GitHub Actions берёт его из секрета **`FABLE_KEYSTORE_B64`** (файл `.jks` в base64, пароль `FABLE_KEYSTORE_PASSWORD` необязателен). Без этого секрета APK подписывается временным ключом: он установится, но следующая версия попросит удалить предыдущую.

## Что умеет приложение

**Ввод**
- Табель: *Начать*, *Перерыв*, *Закончить* — день создаётся сам (по желанию с округлением до четверти часа).
- Ручной ввод: дата, начало → конец (смены через полночь поддерживаются), перерыв, кнопки **+ Сверхурочные** (+15 мин, +30 мин, +1 ч).
- Живой предпросмотр расчёта во время ввода, предупреждение, если два дня пересекаются.
- Повторить день на другие дни недели, дублировать день, принудительно добавить или убрать оплату питания для отдельного дня.

**Места работы** (по одному на работодателя или агентство), у каждого свои правила:
- Тип договора: Временная работа (intérim), Срочный (CDD), Бессрочный (CDI), Другой — почасовая ставка брутто, цвет.
- **Сверхурочные** за неделю или за день, с 2 ступенями (например, +25% с 35 ч, +50% с 43 ч).
- **Ночные часы** в настраиваемом интервале (по умолчанию 21:00 → 6:00) со своей надбавкой.
- **Воскресенья** и **праздники**: по умолчанию календарь **материковой Франции (Париж)** или **Эльзаса-Мозеля** (+ Страстная пятница и 26 декабря), задаётся для всех мест работы.
- Сложение надбавок: суммируются или учитывается только наибольшая; ночь с субботы на воскресенье считается по дню начала или по часам.
- **Оплата питания** за каждый рабочий день или начиная с заданного числа часов, **транспортная компенсация** за день.
- **IFM** (компенсация по окончании временной миссии) или **компенсация по окончании срочного договора** (CDD) и **ICCP** (компенсация за отпуск), по умолчанию 10% + 10%.
- **Расчётный период** — полный месяц или со сдвигом (например, с 21-го по 20-е), часы и перерыв по умолчанию.

**Учёт**
- Главный экран: табель, текущая неделя со шкалой порога сверхурочных, итоги месяца.
- История по месяцам — списком, сгруппированным по неделям, или календарём, с фильтром по месту работы.
- Итоги за неделю / месяц / год: часы, сверхурочные по ступеням, ночь, воскресенья, праздники, отработанные дни, график, расшифровка от брутто до **ориентировочной суммы на руки** (ставка удержаний настраивается).
- **Экспорт в PDF** (табель, готовый к отправке), **Excel .xlsx** и **CSV** — без подписки.

**Остальное**
- Напоминание уведомлением в выбранные дни и время.
- **Всё настраивается** в Настройках: тёмная, чёрная (AMOLED), светлая или автоматическая тема; основной цвет и цвета надбавок (палитра или любой цвет); шрифты; размер текста; скругления; плотность; анимации; формат длительности (7 h 30, 7h30 или 7,5 h); скрытный режим, прячущий суммы; стартовый экран; вид истории. Любой цвет и для каждого места работы.
- Резервное копирование / восстановление в файл `.json`, автоматическая запасная копия в личных файлах приложения.
- Никакие данные не покидают телефон: ни аккаунта, ни сервера, ни рекламы.

## Как это считается

Каждый день делится по минутам. Для каждой отработанной минуты Fable знает, приходится ли она на ночь, воскресенье или праздник и в какую ступень сверхурочных попадает (недельный итог с понедельника по воскресенье, в хронологическом порядке). Перерыв вычитается пропорционально. Неделя на стыке двух месяцев считается целиком, а затем учитываются только дни внутри периода.

- Зарплата брутто = часы × ставка + надбавки
- IFM / компенсация по окончании договора = брутто × 10%
- ICCP = (брутто + IFM) × 10%
- Ориентировочно на руки = итого брутто − удержания (по умолчанию 22%) + питание и транспорт

Это **оценки**: решающее значение имеют твой коллективный договор и расчётный листок.

## Разработка

```bash
npm install
npm run dev        # интерфейс в браузере
npm test           # тесты движка расчёта
npm run sync       # веб-сборка + Android-проект (в первый раз после «npx cap add android»)
npm run open       # открывает проект в Android Studio
```

Структура: `src/core` (расчёты, праздники, хранение, экспорт в PDF/Excel), `src/views` (экраны), `src/ui` (компоненты), `scripts/patch-android.mjs` (название, значки, тема и подпись Android-проекта), `tests/` (тесты движка и сценарии интерфейса).

Стек: HTML/CSS/JS без фреймворка, [Vite](https://vitejs.dev), [Capacitor 8](https://capacitorjs.com), [pdf-lib](https://pdf-lib.js.org). Шрифты Manrope и Unbounded (SIL Open Font License).
